Each player runs once. Runner earns 1000 + time bonus for finishing, or points for distance. Dropper earns 50 per hit. Boxes: Crate (fast reload), Spring (bounces the runner up, careful), Iron (long stun, slow reload). Jump against a wall to climb it. Esc pause · M sound · F full screen.

Solo: set MODE to SOLO. The level never ends and the computer runs the crane, getting 10% better every 100 m. You have 3 lives; save your distance to the online leaderboard.

Online play: set MODE to ONLINE. One player creates a room and reads out the 4-letter code, the other joins with it. Online, each player can use WASD or the arrow keys.
